# WorkArea - Система управления задачами

Веб-приложение для управления задачами и проектами с системой аутентификации пользователей.

## Функциональность

- Регистрация и авторизация пользователей
- Управление профилем пользователя (включая загрузку фото)
- Создание и назначение задач
- Просмотр и фильтрация задач
- Изменение статуса задач
- Система приоритетов и сроков выполнения

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python main.py
```

3. Откройте браузер и перейдите по адресу: `http://localhost:5000`

## Структура проекта

- `main.py` - основной файл приложения с маршрутами
- `control_db.py` - модели базы данных
- `extensions.py` - расширения Flask
- `validators.py` - валидация данных
- `config.py` - конфигурация приложения
- `templates/` - HTML шаблоны
- `instance/` - база данных SQLite
